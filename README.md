# IBM Bob con Xatrix: ejercicios del evento

Material del evento **IBM Bob con Xatrix** (octubre 2026). Cada carpeta es un escenario que el presentador recorre en vivo y que tú puedes reproducir en tu equipo, a la par.

Seguir los ejercicios es opcional. Si prefieres solo observar, todo se hace en pantalla.

## Antes de empezar

1. Instala IBM Bob y activa tu cuenta de prueba en **https://bob.ibm.com/trial?bpid=zu2kp7r**
2. Clona este repositorio:

   ```
   git clone https://github.com/leonardoDN/evento-bob.git
   ```

## Escenarios

| Carpeta | Demostración | De qué se trata |
|---|---|---|
| [`codigo-heredado/`](codigo-heredado/) | 1. Lo que nadie quiere tocar | Entender sistemas viejos (RPG, COBOL y PHP) sin leerlos línea por línea |
| [`pedidos/`](pedidos/) | 2 a 6 | Planear, cambiar, revisar y gobernar una aplicación de pedidos y facturación CFDI 4.0 |

Abre en Bob **la carpeta de cada ejercicio**, no la raíz del repositorio. Cada carpeta trae sus propias instrucciones.

> **Todo el código es ficticio.** Fue escrito para este evento; no proviene de ningún cliente ni sistema real. Las credenciales que aparecen son falsas a propósito.
