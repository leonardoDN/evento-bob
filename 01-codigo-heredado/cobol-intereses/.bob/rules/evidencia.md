# Responder con evidencia

- Cada afirmación sobre el código lleva el archivo y los números de línea que la respaldan.
- Antes de concluir qué hace una rutina, sigue todas las rutinas que llama (subrutinas, párrafos, programas, archivos incluidos y funciones) y revisa qué escriben o actualizan.
- Si la respuesta depende de una condición, revisa también lo que pasa cuando la condición no se cumple.
- Cuando calcules fechas, montos o tasas, hazlo paso a paso con el código tal como está, no con lo que debería hacer.
- Escribe la conclusión al final, después de revisar las líneas, y asegúrate de que coincida con lo que esas líneas muestran.
